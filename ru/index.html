Сворачиваемые группы

Группы аккуратно расположены друг под другом и раскрываются касанием. У каждой группы и будильника свой переключатель.

Дни для группы

Группа будних дней никогда не звонит в выходные. Задайте дни один раз в группе — они применятся ко всем будильникам.

Каждый день новый звук

Пусть каждое утро звучит другой звук из вашего списка, или выберите звук для каждого дня недели.
